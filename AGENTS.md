# fnox-build

Builds, signs and publishes native fnox: jdx/fnox at `FNOX_TAG` plus homescoop's `packages/wasi-fnox` patches at `HOMESCOOP_REF` (applied by its `apply.sh`), for macOS, Linux (static musl) and Windows on arm64 and x64, as `@ai-ecoverse/fnox` plus `@ai-ecoverse/fnox-<os>-<arch>`. Patches go to homescoop, never here, and never upstream. README.md is the spec; keep it in step. No comments in any file. No CLAUDE.md. Tests live in `test/integration/` and drive the built binary. `npm run lint` and `npm test` must pass. Versions are `<fnox version>-slicc.<n>`, cut from `main` by `scripts/release-plan.mjs` from conventional commits. Never move or delete a pushed tag.
